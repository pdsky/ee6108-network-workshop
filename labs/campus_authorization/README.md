# Packet Tracer 校园授权综合实验：学生起点

这个目录把本仓库校园授权学习主题落到 Cisco Packet Tracer 9.0.1 实验中。设备和连线已经搭好，学生需要自己完成 IP、VLAN、Access/Trunk、路由、ACL、SSH 授权与 STP。阶段、时长及评分建议是自拟教学安排；正式 CA 要求以老师发布的文件为准。

## 下载和开始

- [学生实验包 ZIP](Campus_Authorization_Student_Lab.zip)：起点工程、学生手册、六张真实截图与 SHA-256 校验。
- [学生起点 .pkt](Campus_Authorization_Student_Start.pkt)：只需要工程时可单独下载。
- [学生实验手册](学生实验手册.md)：完整地址与端口表、六阶段任务、验收矩阵、记录表和思考题。

在 GitHub 的二进制文件页面点击下载原始文件。解压 ZIP 后先阅读手册，打开起点并另存为自己或小组的 `Working.pkt`。手册的图片与文档保持在同一目录。

## 与网页版本的对应关系

| 版本 | 范围与用途 |
|---|---|
| 本仓库校园六课基础网页 | 14 台基线设备，讲解校园 VLAN 与网站授权 |
| 本目录学生工程 | 17 台设备、17 条连线；加入 R2、REMOTE-SW、Remote-PC 和交换机冗余三角；R2 是远端路由器 |
| 网页冗余进阶提案 | 32 台主/备设备、双核心、RSTP 与 HSRP；对应 Packet Tracer 工程需要另行实现 |

本目录没有实现双网关 HSRP、双核心或服务器热备。目标是单臂路由、远端静态路由，以及 PVST 管理的交换机备用链路。配置以本目录手册为准，避免把三种版本的端口、路由器角色和命令混用。

[校园授权网页源码入口](../../offline/校园网络授权-学习网站.html)。网页动画的授权按钮不会自动配置本工程。

## 六阶段实验

1. IP、ARP 和 MAC 地址学习：默认 VLAN 1 下 A/B 通信。
2. VLAN、Access、Trunk：同 VLAN 互通与跨 VLAN 隔离。
3. R1 dot1Q 子接口、R1/R2 静态路由与远端实验室。
4. 默认 ACL：学生、教师和访客的三网站及远端许可矩阵。
5. AUTH 通过 SSH 实施按来源、按网站的授权、撤销和恢复。
6. STP 根桥、主链路故障、备用路径收敛与恢复。
